# Teaching Platform

面向大学教学的开源智能教学平台，连接老师备课、学生个性化学习与教学反馈。保持课程通用性，不限定具体学科。

**当前状态：需求设计阶段。仓库尚无可运行的平台、安装程序或部署服务。**

## 产品方向

- **老师备课**：支持教材、讲义、大纲或简要主题等不同程度的输入；通过首次偏好采访和逐课确认，生成生动的教案、PPT 及按需提供的讲稿。材料可下载编辑，也可继续与智能体讨论修改，不开发网页编辑器。
- **学生学习**：以个性化智能体对话作为课后作业。先引导、必要时讲解，再检验理解；学懂规定知识点后完成，评分仅为 0 或 1。支持保存进度，以及文字、语音、图片和手写解题上传，不支持视频互动。也支持随时答疑、复习和预习。
- **教学反馈**：智能体提炼最终掌握情况及学习过程中的困难，提出教学改进建议；老师确认后，在既定大纲下按周微调计划和教学材料。
- **学院管理**：学院统一开通账号、分配课程和成员；管理员与秘书按各自权限查看课程使用、作业完成和学习反馈。

当前聚焦课前和课后，暂不提供课堂现场互动功能。以上是已确认的产品方向，不是已上线的功能清单。
